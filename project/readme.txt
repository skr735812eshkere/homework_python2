# Планировщик задач (Task Manager)

## Описание
Консольное приложение для управления личными задачами. Позволяет добавлять, просматривать, удалять, фильтровать и сортировать задачи по приоритету и статусу.

## Функции
- Добавление задачи с уникальным ID, названием, приоритетом (1-5) и статусом (выполнено/не выполнено)
- Просмотр всех задач
- Удаление задачи по ID
- Изменение статуса задачи (выполнено)
- Фильтрация задач по статусу (только выполненные / только невыполненные)
- Сортировка списка задач по приоритету (по убыванию)
- Изменение приоритета задачи

## Технические детали
- Язык: C++
- Хранение данных: в оперативной памяти (используются классы Task и TaskManager)
- Интерфейс: текстовое меню в консоли
- Структура проекта:
  - Task.hpp / Task.cpp — класс задачи
  - TaskManager.hpp / TaskManager.cpp — класс для управления списком задач
  - App.hpp / App.cpp — класс для работы с интерфейсом пользователя
  - main.cpp — точка входа программы
